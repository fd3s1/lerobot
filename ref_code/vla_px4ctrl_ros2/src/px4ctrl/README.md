# px4ctrl ROS2

This package keeps the reference px4ctrl file layout while targeting ROS2 and
MAVROS `setpoint_raw/attitude`. The current controller output path is bodyrate
and normalized thrust, generated by a UDE outer loop and geometric bodyrate
controller.

The active control path is:

```text
RC / odom / cmd / takeoff_land
  -> input.*
  -> PX4CtrlFSM.*
  -> controller.*
  -> mavros_msgs/msg/AttitudeTarget
```

Yaw is always in radians. Cmd yaw is extracted from `PoseStamped.pose.orientation`.
Odom is read from `nav_msgs/msg/Odometry` on `/mavros/local_position/odom`; its
twist is treated as base_link velocity and rotated to world/ENU inside input.*.
